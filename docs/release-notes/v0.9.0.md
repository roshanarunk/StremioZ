The first public StremioZ release: Stremio for the couch on Windows.

**What's in it**
- AnimeJaNai 3.12.5 upscaling for anime, chosen automatically. The preset you pick while watching becomes the default.
- NVIDIA RTX Video HDR and Super Resolution together with AnimeJaNai (TensorRT on Direct3D 11 frames).
- Game controller support on every screen, with an on-screen keyboard, a player menu and button hints.
- TV mode, with a **StremioZ TV mode** shortcut that opens straight into it.
- "For You" recommendations from your watch history on the home banner.
- The Stremio Kai interface (themes, hero banner, enhanced metadata, smart tracks, skip intro).
- Settings → StremioZ for the controller, TV mode, interface size, recommendations and updates.
- Signed automatic updates from this repository.

**Install**

Run `StremioZ-Setup-0.9.0.exe`. It installs for your user, with no admin prompt. On an NVIDIA RTX GPU, keep "NVIDIA TensorRT for AnimeJaNai" ticked (about 0.7 GB, downloaded from NVIDIA's packages). The installer isn't code-signed, so SmartScreen may ask: choose More info → Run anyway.

**Known issues**
- RTX Video HDR needs Windows HDR on for the display, and is tagged as 1000-nit HDR10.
- Stremio's "Play URL/Magnet link" reads the clipboard, so it needs a keyboard or mouse.
